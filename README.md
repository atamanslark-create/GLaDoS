# GLaDoS — личный управляющий Telegram-бот

> «Я буду хранить ваши секреты. В отличие от вас — надёжно.»

## Возможности

| Раздел | Описание |
|--------|----------|
| 💰 **Платежи** | Журнал оплат: наименование, сервис, сумма, хеш **USDT TRC20**. Проверка транзакции в сети TRON через TronGrid. Экспорт в CSV. |
| 📅 **Подписки** | Срок действия, статус, **автопредупреждения** за N дней. Быстрое **продление** одной кнопкой (+месяц / +3 / +6 / +год). |
| 🔐 **Учётные записи** | Логины/пароли. Пароли **шифруются** (Fernet/AES). Показ во всплывающем окне. Встроенный **генератор паролей** (16–32 символа). **Автоудаление** сообщения с паролем из чата. |
| 📁 **Файлы** | Загрузка и хранение документов/фото на диск. Выдача обратно по запросу. |
| 🤖 **Боты** | Управление другими ботами по токену: проверка getMe, отправка сообщений. Токены зашифрованы. **Автомониторинг** каждые N минут с алертом при падении. |
| ⚙️ **Службы** | Реестр интеграций: API-ключи, вебхуки, внешние сервисы. Включение/выключение. |
| 🔍 **Поиск** | Глобальный поиск по всем разделам одним запросом. |
| 💱 **Курсы** | USDT → USD / RUB / EUR / BTC в реальном времени (CoinGecko). |
| 💾 **Бэкап** | Получение файла базы данных прямо в чат. |
| 📊 **Сводка** | Статистика по всем разделам. |
| 🔐 **PIN** | Опциональная защита сессии PIN-кодом с таймаутом. |

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

```bash
export GLADOS_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER"
export GLADOS_OWNER_ID="7774398077"

# Опционально:
export GLADOS_PIN="1234"              # PIN-код (пусто = отключён)
export GLADOS_PIN_TIMEOUT="30"        # таймаут сессии (мин.)
export GLADOS_WARN_DAYS="5"           # за сколько дней предупреждать
export GLADOS_CHECK_TIME="10:00"      # время ежедневной проверки подписок
export GLADOS_BOT_MONITOR_MIN="60"    # интервал мониторинга ботов (мин., 0=откл.)
export GLADOS_FERNET_KEY="..."        # свой ключ шифрования
```

## Запуск

```bash
python bot.py
```

В Telegram: `/start` → кнопочное меню.

## Безопасность

- Пароли, токены ботов и конфиги служб хранятся **зашифрованными** в `data/glados.db`.
- Ключ шифрования — `data/secret.key`. **Потеряете — данные не расшифровать.**
- Сообщения с паролями **автоматически удаляются** из чата.
- При включённом **PIN** бот запрашивает код в начале каждой сессии.
- Доступ только для `GLADOS_OWNER_ID`.

## Структура

```
glados_bot/
├── bot.py              # запуск, планировщики (подписки + мониторинг ботов)
├── config.py           # все настройки
├── glados.py           # личность GLaDoS
├── crypto.py           # шифрование (Fernet)
├── database.py         # SQLite: таблицы и операции
├── keyboards.py        # кнопочные меню
├── utils.py            # генератор паролей, TRON-проверка, курсы валют
├── handlers/
│   ├── common.py       # авторизация, PIN, меню, бэкап, поиск, курсы
│   ├── payments.py     # платежи + CSV + TRON
│   ├── subscriptions.py # подписки + продление
│   ├── accounts.py     # учётные записи + генератор паролей
│   ├── files.py        # файлы
│   ├── bots.py         # управление ботами
│   └── services.py     # службы
└── requirements.txt
```

## Расширение

Новый раздел = новый роутер в `handlers/` + строка в `handlers/__init__.py` + кнопка в `keyboards.main_menu()`.
